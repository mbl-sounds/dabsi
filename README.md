# dabsi

Distributed adaptive blind SIMO identification (DABSI): simulation code and reference implementations for the journal publication.

## Contents

- `dbsi/`: experiment definitions, the process pool runner, parameter tuning and result analysis.
- `lib/`: signal, room and simulation utilities, with Cython kernels (`*_cy.pyx`) for the performance-critical parts.
- `tuned/`: tuned step sizes per experiment. `run_experiments.py` reads these automatically.
- `tune.py`, `run_experiments.py`: parameter tuning and experiment runs.
- `plot_*.py`, `inspect_dsaawet.py`, `export_tuned_params.py`: figures, tables and the LaTeX parameter table.

## Setup

```bash
poetry install
python setup.py build_ext --inplace
```

MYRiAD RIRs and LibriSpeech are downloaded automatically on first use, into `.myriad/` and `.librispeech/` in the working directory. LibriSpeech is only fetched for experiments with speech signals. The LibriSpeech download is large, so the first run takes a while.

## Experiments

Tuning is only needed for experiments without a file in `tuned/`. Existing tuned parameters are used by default (use `--no-tuned` to ignore them):

```bash
python tune.py wgn_rooms --where SNR=20,50 --processes 8
```

Run an experiment. Results go to `.data/<experiment>/`:

```bash
python run_experiments.py simulated_rooms --out .data --processes 8
```

Runs are resumable, finished jobs are skipped. Use `--dry-run` to list the open jobs. To run the main experiments in one go:

```bash
for e in simulated_rooms measured_rooms; do
    python run_experiments.py $e --out .data --processes 8
done
```

| Experiment | Content |
| --- | --- |
| `simulated_rooms` | simulated shoebox rooms |
| `measured_rooms` | measured RIRs (MYRiAD) |
| `prior_mismatch_sweep` | prior strength sweep, simulated rooms |
| `measured_prior_sweep` | prior strength sweep, measured RIRs |
| `scalability` | scalability in M and N_i |
| `dsaawet_sweep` | DSAAWET step size sweep, WGN |
| `dsaawet_sweep_rooms` | DSAAWET step size sweep, shoebox rooms |

Options: `--runs` and `--seed` override the configuration, `--algs` restricts the algorithms.

## Figures and tables

Figures go to `plots/` and tables to `tables/`:

```bash
python plot_results.py .data/simulated_rooms .data/measured_rooms 
python plot_room_results.py --snr 30
python plot_prior_sweep.py .data/prior_mismatch_sweep .data/measured_prior_sweep
python plot_scalability.py .data/scalability
python inspect_dsaawet.py .data/dsaawet_sweep
python plot_tuning.py tuned/prior_mismatch.json --out figures/tuning
python export_tuned_params.py
```

`export_tuned_params.py` writes `tables/parameters_tuned.tex`. Do not edit this file by hand.
